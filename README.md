# Four Card Feature Section

A responsive solution to the Frontend Mentor Four Card Feature Section challenge.

## Overview

The component presents four product features in a balanced responsive layout that moves from a single column on small screens to a three-column composition on larger screens.

## Built With

- Semantic HTML5
- Modern CSS
- CSS Grid
- Responsive design
- Accessible decorative imagery
